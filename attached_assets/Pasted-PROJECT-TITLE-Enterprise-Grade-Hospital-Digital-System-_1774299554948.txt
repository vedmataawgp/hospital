PROJECT TITLE: Enterprise-Grade Hospital Digital System

STRICT ARCHITECTURE RULES (NON-NEGOTIABLE):

1. FRONTEND:

* MUST use Next.js (latest stable, App Router).
* MUST be used ONLY for frontend (UI, SSR/SSG, API consumption).
* DO NOT create any backend logic in Next.js.
* DO NOT create API routes in Next.js.
* DO NOT store business logic in Next.js.

2. BACKEND:

* MUST use Django (latest stable) + Django REST Framework.
* ALL backend logic, APIs, authentication, database handling MUST be in Django ONLY.
* Next.js must ONLY consume Django APIs.
* REPEAT: Backend MUST be Django. Do NOT generate backend in Next.js under any condition.

3. DATABASE:

* Use PostgreSQL (production-ready).
* ORM: Django ORM.
* Use proper indexing, relations, and optimized queries.

---

SYSTEM REQUIREMENTS:

Build a COMPLETE Hospital Management + Patient Experience Platform including:

MODULES:

* Patient Management System (records, history, reports)
* Appointment Booking System (real-time slots, queue handling)

* Online Consultation (chat + video-ready API hooks)
* Digital Documents (forms, discharge summary)
* Billing & Payments
* Notifications (email/SMS ready structure)
